# UB12-10-CRT3 — grupo IBSCBS exigido para CRT 3

## O que a regra diz

Para emitente de CRT 3, a ausência do grupo `IBSCBS` no item gera a rejeição 1115 em produção a partir de 2026-08-03 (em homologação, desde 2026-07-01).

## Como esta base aplica

A vigência registrada é a de produção. Homologação está no quick-reference; se um software precisar distinguir ambiente, crie uma regra própria para homologação.
