# UB12-10-EXC1 — exceção para notas que referenciam documento anterior

## O que a regra diz

NF-e com finalidade de ajuste ou devolução (`finNFe` 2 ou 4) que referencia NF-e emitida antes do ano de corte não tem o grupo exigido; a ausência gera apenas aviso.

## Como esta base aplica

O ano de corte aparece rasurado no texto ("2026" riscado, "2027" escrito por cima). Esta base usa 2027 — por isso o status é `premissa`, e o conflito está explicado no `index.md`.
